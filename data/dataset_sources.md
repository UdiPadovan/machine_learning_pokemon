# Fontes do Dataset

## Pokémon

Foram utilizadas imagens de Pokémon para treinamento
do classificador visual.

## Objetivo

As imagens são utilizadas exclusivamente no contexto
educacional do projeto de Machine Learning desenvolvido
para uma feira tecnológica escolar.

## Organização

Cada imagem é associada a uma das 151 classes da
primeira geração.

## Processamento

As imagens são redimensionadas e submetidas a técnicas
de data augmentation durante o treinamento.
